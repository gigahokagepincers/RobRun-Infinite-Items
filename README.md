## 🎯 What Is This?

`RobRun‑Infinite‑Items` is a **configuration and preset manager** built for the popular Roblox game **RobRun**.  
It lets you:

* **Create** custom item lists that never run out.  
* **Swap** between presets on the fly without leaving the game.  
* **Share** your curated load‑outs with friends or the community.  

All of this is done with a clean, script‑free UI that works directly inside Roblox Studio.

## 📋 How to Create Your Own Preset  

1. Open the **Infinite Items** panel (`View → Toolbars → Infinite Items`).  
2. Click **New Preset** and give it a descriptive name.  
3. Drag items from the **Roblox Catalog** into the list.  
4. Set a custom quantity (e.g., `∞` for truly endless).  
5. Hit **Save** – the preset is stored as a JSON file in `presets/`.  

You can now load this preset in any RobRun map by selecting it from the drop‑down menu.
